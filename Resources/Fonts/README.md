# Bundled typefaces

The typefaces the agencies' own websites use for lettering, bundled so the station signs can use
them. All are under open licences that allow bundling with software.

| File | Used for | Website | Licence |
|---|---|---|---|
| Roboto-Medium.ttf, Roboto-Bold.ttf | MDOT MTA: MARC, Light RailLink, Metro SubwayLink | mta.maryland.gov | SIL OFL 1.1 (LICENSE-Roboto.txt) |
| Montserrat-SemiBold.ttf, Montserrat-Bold.ttf | VRE | vre.org | SIL OFL 1.1 (OFL-Montserrat.txt) |
| OpenSans-SemiBold.ttf, OpenSans-Bold.ttf | Amtrak | amtrak.com | SIL OFL 1.1 (OFL-OpenSans.txt) |
| PublicSans-SemiBold.ttf, PublicSans-Bold.ttf | NJ TRANSIT | njtransit.com | SIL OFL 1.1 (OFL-PublicSans.txt) |

Roboto, Montserrat and Open Sans: Latin subsets, from Fontsource. Public Sans: v2.001 from
github.com/uswds/public-sans. WMATA's Helvetica Now is commercially licensed and isn't bundled;
the app uses macOS's Helvetica Neue, which wmata.com names as its fallback. MTA (New York),
PATH and MBTA sign in Helvetica and PATCO in Verdana, which macOS includes.
